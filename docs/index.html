Doomsday in 8086 Assembly

Conway's Doomsday algorithm, written from scratch in NASM — with a browser IDE that assembles and runs it, so DOSBox is optional.

Open the IDE ▶

What the IDE is

Real DOSBox, compiled to WebAssembly, with NASM installed inside it. You write 8086 assembly, press Run, and a DOS machine boots, assembles your source, and executes it — entirely in the browser. Nothing is sent anywhere; there is no server.

Because it is genuinely DOS and genuinely NASM, anything that works here works in a real DOSBox. It is a faster way to run the same toolchain, not a simulation of it.

Writing code for it

  • Flat .COM programs: start with org 100h
  • Print with int 21h, AH=09h ($-terminated) or AH=02h
  • Read a line with AH=0Ah, a character with AH=01h
  • Exit with AX=4C00h
  • NASM syntax, not MASM: no .MODEL, and a label is already its address

The algorithm

Every year has a weekday — its doomsday — that a known set of easy dates all land on. Find it, and any date is a short hop away. The same algorithm was implemented in C++ first; that version and its explanation live in the Doomsday project.

Runs on js-dos (DOSBox, GPL-2.0) and NASM (BSD-2). No trackers, no backend.
